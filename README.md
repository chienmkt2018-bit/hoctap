# HOC TAP QUEST

Nền tảng học tập theo phong cách trò chơi — bộ khung khởi tạo.

## Công nghệ

- React + TypeScript
- Vite
- CSS responsive, nền tối với điểm nhấn tím–cyan

## Yêu cầu

- Node.js 20.19+ hoặc 22.12+
- npm

## Chạy trên Windows

Mở PowerShell tại thư mục dự án:

```powershell
cd frontend
npm install
npm run dev
```

Mở URL được Vite hiển thị trong terminal (thường là http://localhost:5173).

## Kiểm tra bản build

```powershell
cd frontend
npm run build
npm run preview
```

## Phạm vi hiện tại

Đây là bộ khung P1.1. Dashboard, Quest Map, đăng nhập, API và cơ sở dữ liệu sẽ được triển khai ở các bước tiếp theo. Chưa có thông tin đăng nhập hoặc bí mật nào được lưu trong mã nguồn.
